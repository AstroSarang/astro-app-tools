यह research/comparison file है, नया product नहीं। नीचे हर version की backtest accuracy लिखी है - कोई भी version 60% से ऊपर नहीं गया है, इसलिए इनमें से किसी को भी working prediction tool की तरह इस्तेमाल नहीं करना है। सभी 9 versions के logic मूल Python/JS sources से faithful port किए गए हैं, कोई नया logic नहीं बनाया गया है।

9. KP 5th CSL (कृष्णमूर्ति पद्धति - पंचम भाव उप-स्वामी)
